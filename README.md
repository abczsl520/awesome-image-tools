# 🖼️ Awesome Image Tools

Free online image tools - resize, convert, compress, and edit.

## Convert
- [JPG to PNG](https://img-kit.com/tools/jpg-to-png/) - Convert JPEG to PNG
- [PNG to JPG](https://img-kit.com/tools/png-to-jpg/) - Convert PNG to JPEG
- [Image to ICO](https://img-kit.com/tools/image-to-ico/) - Create favicon

## Edit
- [Image Resizer](https://img-kit.com/tools/image-resizer/) - Resize images online
- [Image Cropper](https://img-kit.com/tools/image-cropper/) - Crop images
- [Mini-Tools.uk Image Tools](https://mini-tools.uk/image) - Self-recommending a browser image resize, crop, and compress tool with local preview and JPG/WebP export for quick image optimization and dimension changes.
- [Add Text](https://img-kit.com/tools/add-text-to-image/) - Add text overlay

## Optimize
- [Image Compressor](https://img-kit.com/tools/image-compressor/) - Compress images
- [Bulk Resize](https://img-kit.com/tools/bulk-resize/) - Resize multiple images
